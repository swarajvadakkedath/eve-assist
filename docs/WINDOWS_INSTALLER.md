# Windows Installer Architecture

## Overview

Eve Desktop is distributed as a single NSIS (Nullsoft Scriptable Install System) installer executable (`Eve_1.0.0_x64-setup.exe`). The installer bundles the application binary, frontend assets, embedded Python runtime, launcher module, backend module, and all Python dependencies into a single LZMA-compressed package.

## Installer Structure

```
Eve_1.0.0_x64-setup.exe
│
└── Installed to: %LOCALAPPDATA%\Programs\Eve OS\
    │
    ├── eve-desktop.exe          (Tauri shell — 26 MB)
    ├── resources/
    │   ├── python/              (Embedded Python 3.12.9 — 273 MB raw)
    │   │   ├── python.exe
    │   │   ├── pythonw.exe
    │   │   ├── python312.dll
    │   │   ├── python3.dll
    │   │   ├── python312._pth   (path configuration)
    │   │   ├── python312.zip    (stdlib)
    │   │   ├── Lib/
    │   │   │   └── site-packages/   (pip-installed deps)
    │   │   ├── DLLs/
    │   │   └── ...
    │   ├── launcher/            (launcher module — 28 .py files)
    │   └── backend/             (backend module — aios package)
    ├── icons/
    └── LICENSE
```

## Installer Configuration

- **Install Mode**: CurrentUser (`%LOCALAPPDATA%\Programs\Eve OS\`)
- **Compression**: LZMA (solid compression)
- **Language**: English
- **Start Menu Folder**: Eve OS
- **Installer Icon**: `icons/icon.ico`
- **License**: MIT

## NSIS Configuration Source

The NSIS configuration is generated by Tauri from `desktop/src-tauri/tauri.conf.json`:

```json
{
  "nsis": {
    "installMode": "currentUser",
    "languages": ["English"],
    "displayLanguageSelector": false,
    "startMenuFolder": "Eve OS",
    "installerIcon": "icons/icon.ico",
    "compression": "lzma"
  }
}
```

## Installation Process

1. User downloads `Eve_1.0.0_x64-setup.exe`
2. User double-clicks the installer
3. Windows SmartScreen may prompt — click "Run anyway"
4. NSIS installer extracts to temporary directory
5. License agreement displayed (if configured)
6. Files copied to `%LOCALAPPDATA%\Programs\Eve OS\`
7. Desktop shortcut created: `%USERPROFILE%\Desktop\Eve OS.lnk`
8. Start Menu shortcut created: `Start Menu\Programs\Eve OS\Eve OS.lnk`
9. Uninstaller registered in Windows Programs and Features
10. Eve launches (optional, currently disabled)

## Uninstall Process

1. User opens Settings → Apps → Installed apps
2. Finds "Eve OS" and clicks Uninstall
3. Or runs `%LOCALAPPDATA%\Programs\Eve OS\Uninstall Eve OS.exe`
4. All application files removed
5. User data in `%USERPROFILE%\.eve\` is NOT removed

## Build Command

```powershell
cd desktop
npm run eve:build
```

This runs:
1. `npm run bundle:python` — downloads and configures embedded Python
2. `npm run build:frontend` — builds React frontend
3. `npm run tauri:build` — compiles Rust + generates NSIS installer

## Troubleshooting

**"Installer failed to start"**: Ensure Windows is up to date and you have admin rights (not required for currentUser mode, but some anti-virus may block).

**"Python not found" error at runtime**: The embedded Python at `resources/python/python.exe` may be missing or corrupted. Reinstall Eve.

**"WebView2 not installed"**: Tauri uses the WebView2 runtime, which is included with Windows 11 and recent Windows 10 updates. If missing, the installer will prompt to download it.

**Blank window on launch**: The frontend assets may not be bundled correctly. Check `resources/` directory for `python/`, `launcher/`, and `backend/` subdirectories.
