# Release Pipeline

## Overview

The Eve Desktop release pipeline produces a single NSIS installer executable containing the application, embedded Python runtime, and all dependencies. The pipeline is designed to run on any Windows machine with the required build tools.

## Build Prerequisites

| Tool | Version | Purpose |
|------|---------|---------|
| Rust | stable (MSVC or GNU) | Compile Tauri shell |
| Node.js | 18+ LTS | Build React frontend |
| npm | 9+ | Package management |
| Python | 3.12+ | Bundle dependencies (build only) |
| NSIS | 3.08+ | Generate installer |

## Build Commands

### Full Release (One Command)

```powershell
cd desktop
npm run eve:build
```

### Step by Step

```powershell
cd desktop

# 1. Bundle embedded Python (download + configure + install deps)
npm run bundle:python

# 2. Build React frontend
npm run build:frontend

# 3. Build Rust binary + generate NSIS installer
npm run tauri:build
```

### Quick Binary Only (No Installer)

```powershell
cd desktop
npm run eve:build:debug
# Produces: desktop/src-tauri/target/debug/eve-desktop.exe
```

## Pipeline Stages

### Stage 1: Bundle Python (`bundle-python.ps1`)

```
bundle-python.ps1
├── Download python-3.12.9-embed-amd64.zip (10.6 MB)
├── Extract to src-tauri/python/
├── Configure python312._pth
├── Download get-pip.py
├── Install pip
├── pip install -r requirements.txt → Lib/site-packages/
├── Copy launcher/ module
├── Copy backend/ module
└── Clean up __pycache__
```

**Duration**: 2-5 minutes (depends on network and dependency count)
**Output**: `dektop/src-tauri/python/` (~273 MB)

### Stage 2: Build Frontend (`vite build`)

```
vite build
├── Transform 127 modules
├── Render chunks
├── Gzip computation
└── Output to src/frontend/dist/
    ├── index.html (0.45 KB)
    ├── assets/index-BIQ1KEst.css (107.85 KB)
    └── assets/index-CXahS12_.js (300.01 KB)
```

**Duration**: 3-5 seconds

### Stage 3: Build Rust Binary (`cargo build --release`)

```
cargo build --release
├── Compile tauri v2.x (several plugins)
├── Compile eve-desktop v1.0.0
└── Output: target/release/eve-desktop.exe (26.1 MB)
```

**Duration**: 2-4 minutes
**Linker**: LLD (faster than default)
**Strip**: --strip-all (reduces binary size)

### Stage 4: Generate Installer (`tauri build`)

```
tauri build
├── Patch binary with NSIS metadata
├── Download NSIS toolchain (cached)
├── Generate NSIS script
├── makensis → Eve_1.0.0_x64-setup.exe
└── Output: target/release/bundle/nsis/Eve_1.0.0_x64-setup.exe
```

**Duration**: 1-3 minutes
**Installer Size**: ~89 MB (LZMA compressed)

## Artifacts

| Artifact | Path | Size |
|----------|------|------|
| Installer | `target/release/bundle/nsis/Eve_1.0.0_x64-setup.exe` | 89.3 MB |
| Binary | `target/release/eve-desktop.exe` | 26.1 MB |
| Frontend dist | `../../src/frontend/dist/` | 0.4 MB |
| Python bundle | `python/` | 272.5 MB |

## NSIS Installer Internals

The NSIS installer is generated by Tauri's bundler. Key aspects:

- **Compression**: LZMA (solid compression, best ratio)
- **Install mode**: CurrentUser (`%LOCALAPPDATA%\Programs`)
- **Shortcuts**: Desktop + Start Menu
- **Uninstaller**: Registered in Windows Apps & Features
- **Architecture**: x64 only

## Post-Build Verification

```powershell
# Verify installer exists
Test-Path "target/release/bundle/nsis/Eve_1.0.0_x64-setup.exe"

# Check installer size
Get-ChildItem "target/release/bundle/nsis/Eve_1.0.0_x64-setup.exe" | Select-Object Length

# Verify binary was built
Get-ChildItem "target/release/eve-desktop.exe" | Select-Object Length

# Test bundled Python
& "python/python.exe" --version

# Verify launcher import
& "python/python.exe" -c "import launcher.tauri_integration; print('ok')"
```

## Version Management

Application version is defined in:
1. `desktop/src-tauri/Cargo.toml` — Rust package version
2. `desktop/package.json` — npm package version
3. `desktop/src-tauri/tauri.conf.json` — Tauri product version
4. `launcher/__init__.py` — Launcher version

**All must be updated together on release.**

## Known Build Issues

### "The system cannot find the file specified"
- Usually a missing resource file
- Check `tauri.conf.json` resource paths are correct relative to `src-tauri/`
- Check `frontendDist` path

### "makensis.exe not found"
- NSIS not installed or not on PATH
- Install with: `winget install NSIS.NSIS`
- Or manually from: https://nsis.sourceforge.io

### "Linker errors" (too many symbols)
- See `.cargo/config.toml` for LLD workaround
- GNU target requires `--exclude-all-symbols` flag

### NSIS Installer Generation Fails
- Try clearing NSIS cache: `Remove-Item -Recurse -Force "$env:TEMP\.tmp*" -ErrorAction SilentlyContinue`
- Ensure NSIS is in PATH: `$env:Path += ";C:\Program Files (x86)\NSIS\Bin"`
